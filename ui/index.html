O agente paga.
A prova é pós-quântica.
O juiz é a chain.

Três cliques, nenhum truque: cada passo azul na sala de máquinas é uma transação ou consulta real na Stellar testnet, com link pro explorer. O servidor nunca decide nada sozinho.

1

Emitir a credencial

Um secret novo vira um leaf pelo prover real (Poseidon2-M31). O emissor registra o leaf. O secret nunca sai do agente.

2

O agente paga a API

402 → prova STARK de produção (40 queries, ~11ms) → o contrato verifica e queima o nullifier na mesma transação → conteúdo pago liberado.

3

Tentar roubar: reusar a mesma prova

A mesma prova, byte a byte, de novo. O servidor recusa. E ainda que o servidor fosse desonesto: perguntamos direto ao contrato, e o consenso responde.
